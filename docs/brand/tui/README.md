# KRD · 寄居蟹（TUI 版 logo）

吉祥物定了：**寄居蟹**。壳 = `shell` = 你那个 SSH 会话，桌面住进终端壳里，换壳不换人。

所有图都在终端里画，同一份 96×96 矢量造型实时栅格化成两种渲染：

| 渲染 | 做法 | 看起来像 |
| --- | --- | --- |
| **拟物 solid** | 2× 超采样 → 24-bit 真彩 `▀`（上半块：fg=上像素，bg=下像素） | 一张图 |
| **字符 plain** | 每格取占多数的材质 → 一个字符（`@#+:.`） | 一张字符画 |

```sh
node logo-tui.mjs                 # 全屏 TUI：1-5 换动物 · s 拟物/字符 · a 抓屏动画 · q 退出
node logo-tui.mjs --test          # 70 种终端尺寸下自检：每屏严格 cols×rows，边框不缺
node logo-tui.mjs --banner        # --help 用的 5 行大写字标
node logo-tui.mjs --art           # 46×23 的字符版寄居蟹（README / demo）
node logo-tui.mjs --favicon x.svg --px 32
node logo-tui.mjs --shot out.html --cols 116 --rows 38 --animal hermit
```

零依赖，一个文件。造型在 `ANIMALS[].draw()` 里，改一处两种渲染一起变。

## 全屏 TUI 的做法

- **alt screen**（`?1049h`）+ 隐藏光标；退出还原。
- 每帧先 `\x1b[{row};1H` 再 `\x1b[2K` 清行，逐行原位重画 —— 不靠终端自己擦，也不整屏清屏闪烁。
- 宽度一律按**显示列**算：CJK 记 2 列，`fit()` 把每一行裁到恰好 `cols`，宽字符跨过边界就整块丢掉再补空格。终端因此**永远不会折行**，边框也就不会断。
- 底边框永远在最后一行（先收内容、再补空行、最后画边），所以再小也不会出现半边框。
- `SIGWINCH` 重排；放不下时降级成一句提示，而不是画一半。
- 宽了就左右排（画面在左、说明在右，画面能到 48 行），窄了就上下排。

`--test` 会真的把 7 种宽度 × 5 种高度 × 2 种渲染都排一遍，断言行数、每行宽度、首尾边框。

## 造型

- **壳**：厚度 → 实体 → 内侧暗面 → 螺旋脊 + 脊的暗边 → 外缘高光，五层；壳口是暗洞 + 压在外面的唇。
- **腿**：三条，每段有膝，末端收成尖三角。
- **眼**：两根上粗下细的眼柄，眼珠带高光点。
- **钳**：腕 → 掌 → 上下两个颚，开口朝右，颚尖两个白点。
- **可爱**：大眼（半径 9.5）+ 高光点 + 腮红 + 微笑，壳比身子大一倍 —— 头大身小是可爱的全部秘密。
- **16px 折叠**（`fold()`）：只留壳 + 两根眼柄 —— 螺旋在小尺寸仍然认得出。

## 配色

寄居蟹用**自然色**，不是品牌蓝：壳是沙色 `#D9C4A1` + 奶油脊 `#F4E7CC` + 棕色螺纹 `#8A6A46` / `#5B4530`，
蟹身珊瑚 `#F18A5E` / `#C76040`，眼睛奶白 + 黑瞳 + 白高光。品牌蓝 `#5EB8FF` 只留**瞳孔里那一点高光**——
一眼是寄居蟹，第二眼才发现那是 krd 的蓝。

不用渐变、不用阴影：体积全靠明暗两层。

**为什么能直接搬进 Swift**：这一版只用到 4 种图元（椭圆、圆角矩形、折线胶囊、多边形），
