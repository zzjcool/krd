# 寄居蟹 · 设计笔记

这一份是**为什么**，不是怎么用（用法见 `README.md`）。写下来是因为上一版画到一半把笔记丢了，
下次接手的人只能重新猜一遍。

## 一个造型，三个渲染器

2026-10 之前，蟹存在三份：README 的 PNG（整卡截图，黑底烧进图里，#85 就是说这个）、
lab 里的 12 个形状、以及 `LoadingView.swift` 里手抄的同一组 12 个形状。三份已经不一样了——
手抄的那份壳更棕、眼睛更小，而且没人发现，因为没有测试比得出"这不是同一只蟹"。

现在的形状是：**路径只写一遍**，`mascot.mjs` 是源。SVG 是 `vector.mjs` 的写出器，
终端精灵图是它自己的光栅器，加载卡是 CoreGraphics 读生成的 Swift。三份要漂，得同时改三处。

代价是 `MascotArt.swift`（~20 KB）入库。这是有意的：krd 是给人 `swift build` 的，
不能在构建时依赖 node。生成物靠 `make mascot` + `make mascot-check` 防漂。

## 小尺寸：一个 dot 一个采样

两个传输要的东西不一样：

- **图片卡**（终端自己播）放大到 288×360，边缘要软 → 2×2 超采样 + 平均 + 抗锯齿。
- **半块卡**（终端不播）一格就是一个颜色，36 dot 里大半是边缘 → 平均出来的第三色是"没人选过的颜色"，
  一条腿会变成一团泥。

所以半块路径是 **1 个 dot 采一个点、关抗锯齿、吸到造型自己的调色板**。判决性的一条：
36 dot 上的抗锯齿只会把瞳孔洗成灰蓝。

试过、被否掉的：

| 做法 | 结果 |
| --- | --- |
| 1× 采样 + 抗锯齿 + 平均 | 瞳孔洗白，眼睛像空圈 |
| 3× 超采样 + 平均 + 吸附调色板 | 螺纹和沙色混出的中间色吸附到 `#ffb48c`，壳上出现一圈**珊瑚色** |
| 3× 超采样 + 多数色（≥5/9） | 螺纹断了，壳边的墨线也断 |
| **1× + 关抗锯齿 + 吸附调色板** | ✅ 交付的这个 |

lab 里半块卡用的是同一个规则（`logo-tui.mjs` 的 `cardDots`，不是 `pixels`）：lab 要是另一套规则，
它就是"另一种意见"，而不是这张卡的预览。

## 描边：单位

`minPx` 是**输出像素**，`setLineWidth` 收的是**用户单位**，中间隔着 `scale`。
第一版把 `max(w·scale, minPx·ss)` 直接喂给 `setLineWidth`，于是地板的 2.1 px 变成了 2.1 *用户单位*：
半块卡上是 0.24 缓冲像素（发丝线——只因为非抗锯齿的发丝线仍会压到某些 dot 中心，壳边才勉强连着，
看起来是虚线），图片卡上是 1.2 缓冲像素，抗锯齿一摊开，**整张图的墨全没了**：壳边、螺纹、眼圈的描边
一起消失，只剩颜色块。

修法是除回去（`buffer / scale`），除数就是同一个 `scale`。图片卡因此从"没有描边"变回"有描边"，
字节从 6.9 KB 涨到 8.6 KB——那是本来就在画里的墨，不是新增的装饰。

还有一条：**地板对两条路都生效**。36 dot 上 `w=12` 的螺纹只有 1.4 dot 宽，落在像素中心之间时
会一段一段消失；图片卡 2.1 输出像素、半块卡 2.1 dot，两边都够连成线（地板的一半会被填充盖住）。

## 为什么图片卡也用 lo

36×45 的图片被终端放大 8 倍。拿 `hi` 的 69 层去画 36×45，腿和钳会糊成一块深色，
壳的螺旋变成一圈灰——**细节越多越糊**。lo 的 22 层是给这个尺寸设计的：两只大眼、一圈螺纹、
一个开口、一张嘴，放大 8 倍仍然认得出。所以两条传输共用 lo，只有 README 和社交图那类大尺寸产物用 hi。

## 八拍为什么是回文

`peek = [0.05, 0.45, 0.8, 1, 1, 1, 0.8, 0.45]`：缩着 → 伸出来 → 眨眼 → 缩回去。
出去和回来走同一条路，所以第 2 拍和第 6 拍的画**逐像素相同**——这不是 bug，
`MascotArtTests` 里专门有一条断言钉住它（"退场重走进场"），免得以后有人把它当重复帧"修"掉。

眨眼的第 4 拍：眼睛整颗换成珊瑚色的闭合形（眼柄还在），不是把眼白压扁——压扁在小尺寸上
看起来像眯眼，不像眨眼。

## 16px

早先给 16 px 单独画过一份 `fold()`（壳 + 两只眼，没有身体没有眼柄），因为眼柄在 16 px 上只有半个像素，
像两根毛刺。后来还是删了：一份只在 16 px 存在的造型，跟"路径只写一遍"直接冲突，而且它烂掉没人会看见。

现在 `--favicon` 是 **`lo` 画在 14 dot 上**，外面套一圈 `#080a10` 的圆角 tile：
16 px 时身体和嘴各剩一个像素，靠 tile 在浅色/深色标签栏上都还立得住（一张透明底的 16 px 蟹
在浅色栏里就散成几点沙色）。点阵每行一 run 一个 `<rect>`、`crispEdges`，缩放不糊。

## 取景框

`spriteView()` = 8 拍里每一拍 `bounds()` 的并集 + 6% 边距。为什么不是写死一个框：
姿态会让眼柄上下移动 30 单位，写死的框在某一拍上会把眼睛切掉。
`MascotArtTests.testTheSpriteFitsInsideItsView` 守这条：36 dot 的边框上不许有墨。
